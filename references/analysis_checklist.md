# 人际动力学分析 · 自检清单

每次执行 `interpersonal-dynamics-analysis` skill 时，在分析产出前逐项核对。✅ = 已满足。

## A. 素材摄入与还原
- [ ] 图片/截图已用 Read 工具读取并逐条转写（不凭记忆）
- [ ] 对话/事件按时间线还原，区分"用户真实意图"与"表面内容"
- [ ] 缺失信息已标注"推测"，未编造

## B. 证据溯源
- [ ] 每段/每事件挂了溯源标记（R1/R2…、B、N1/N2…、Q1…、Y-*、S）
- [ ] 结论句末尾标注了对应证据
- [ ] 实锤行为（截图/亲历）与心理推测已区分

## C. 四维分析（每方独立）
- [ ] 沟通模式：引用了原文/具体事件
- [ ] 情感模式：高/低共情、供给强弱
- [ ] 冲突处理：正面/回避/撤退/道德化/断联
- [ ] 自我叙事：核心自我身份 + 最怕失去的自我感

## D. 结构模型
- [ ] 为每方建立了双轴结构（获取轴 × 付出轴）
- [ ] 指出了双方轴的对称/镜像/错配关系
- [ ] 串出了双向互动闭环，并钉死"触发点在谁"

## E. 排除性诊断（用户怀疑人格障碍时必做）
- [ ] 区分了"受害者有罪论"与"责任转移"
- [ ] 区分了"精致利己"与"防御性自利"
- [ ] NPD/煤气灯做了核心机制对照 + 反向排除
- [ ] 结论标注"模式识别，非临床诊断"

## F. 澄清与修正
- [ ] 需要时用了 AskUserQuestion（是/否/不确定）
- [ ] 收到回答后**诚实标注**哪些原判断被推翻
- [ ] 未偷偷改写旧结论

## G. 输出物
- [ ] 产出 HTML 图文报告并用 present_files 预览
- [ ] 报告含：执行摘要 / 各方四维 / 双轴模型 / 互动闭环 / 排除诊断 / 红旗清单
- [ ] 配色中性专业，未套用红涨绿跌
- [ ] 用户要求转发时，已生成去个人化版本
- [ ] 所有判断可溯源、可复核

## H. 伦理红线（任一为否即停止分析）
- [ ] 未对未成年人性化、未涉政治敏感
- [ ] 未武断贴 NPD/煤气灯标签（证据不足时写"不足以下此结论"）
- [ ] 关系决策权归属用户，未替其决定断联/在一起
- [ ] 无急性心理危机（有则引导专业求助）
